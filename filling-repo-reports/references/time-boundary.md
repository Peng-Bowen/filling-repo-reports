# 时间边界与数据隔离

## 时间语义

设 T 为估值表明确标注的估值日期。文件名日期只用于交叉核对，不能覆盖表内估值日期。

报表口径是 T 日收盘后仍存续的回购头寸：

> 开始日期 ≤ T 且 到期日期 > T

到期日期等于 T 的交易视为当日已到期，不进入收盘后存续头寸。不要因为它仍出现在到期浏览表中就保留。

## 先截断，再计算

任何费用拆分、排序、汇总和勾稽之前，先完成以下筛选。

### 回购到期浏览表

- 正回购：融入资金大于 0，卖出日期或凭证日期不晚于 T，到期日期严格晚于 T。
- 逆回购：融出资金大于 0，买入日期或凭证日期不晚于 T，到期日期严格晚于 T。

### 交易查询

- 交易状态为成交确认；
- 交易方向为质押式正回购或质押式逆回购；
- 交易日期不晚于 T；
- 到期结算日期严格晚于 T；
- 结算金额大于 0。

交易查询“结算金额（元）”是资产要素登记 AJ“回购标的金额”的直接来源。回购到期浏览表的融入资金/融出资金仅用于存续识别和交叉核对，不得覆盖结算金额。

### 必须排除

- T 之后发生的交易；
- 审批中、撤销、未确认或其他非成交确认状态；
- 到期日等于或早于 T；
- 结算金额为 0 的质押券拆分行；
- 无法与估值表期末余额对应的记录。

同一外部成交编号有多个抵押券明细时，只让承载非零结算金额的主交易生成报表资产。零金额行可以作为匹配证据，但不得增加交易笔数、金额或费用。

## 数据源与目标隔离

### 填写模式

只用源文件和报告日前有效的静态参数生成结果。历史已填报表不得作为当期取值来源。

### 核验模式

必须按以下顺序：

1. 仅加载 3 份源文件；
2. 完成筛选、匹配、计算和源数据结果固化；
3. 执行未来数据扰动测试；
4. 最后才读取已填报表作为预期结果比较。

禁止边看已填结果边调整匹配、顺序、公式或分类。

## 静态主数据的有效期

以下项目不是交易数据，但也必须使用 T 日已经生效的版本：

- 产品简称和发行机构代码；
- 正逆回购编码前缀；
- 币种落盘值；
- 年利率存储格式；
- 资产类别、计息基础和回购标的类别；
- 市场映射；
- 对手方类型字典；
- 交易所匿名对手方和备注规则；
- 允许的金额差额。

不得用当前最新版字典回填历史报告，除非字典明确规定追溯生效。

## 文件可得时间

日常周报/月报在源文件生成后填写，可以使用这些报告日快照。

若任务是历史回测、模拟当时决策或训练预测模型，还必须检查文件实际到达时间。文件内容标注 T 不代表文件在 T 日当时已经可用。

## 未来信息扰动测试

核验时至少做两项反事实检查：

1. 修改所有 T 之后交易的金额、费用、状态和对手方，结果必须不变；
2. 修改所有到期日不晚于 T 的本金和利息，结果必须不变。

若结果变化，说明筛选顺序、范围或匹配逻辑存在未来信息泄漏，停止交付。

## 禁止的合理化

| 说法 | 正确处理 |
|---|---|
| “同日到期还在源表里，所以保留” | 源表是浏览范围，不是收盘后存续定义；必须排除 |
| “先把全表汇总，再减未来交易更方便” | 未来交易已经参与费用和统计；必须先截断 |
| “目标报表能帮助确定匹配” | 目标只能最后比较，不能反向参与生成 |
| “字典只是静态数据，用最新的没关系” | 历史分类可能变化，必须按生效日期选择 |
