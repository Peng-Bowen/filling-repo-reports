# 核验、停止条件与交付

## 逐笔检查

每笔记录必须满足：

- 两份报表资产编码一致；
- 代码、方向、起息日、到期日、本金、市场和对手方回溯到同一交易；
- 到期日严格晚于报告日；
- 净价有估值表单笔依据或可审计的拆分过程；
- 全价减净价等于报告日应计利息；
- 数量等于净价；
- 回购标的金额等于交易查询“结算金额（元）”；
- 回购到期浏览表的融入资金/融出资金只作交叉核对；不一致时已记录差异，且未覆盖结算金额；
- 年利率业务数值与交易查询一致，落盘类型符合配置；
- 编码无重复、无科学计数法、无多余空格。

## 分类汇总

分别按以下维度汇总：

- 正回购与逆回购；
- 交易所与银行间；
- 普通质押式回购与协议回购；
- 同一回购代码；
- 净价、应计利息、全价和交易本金。

正回购：

> 明细净价合计 = 估值表卖出回购本金部分  
> 明细应计利息合计 = 估值表卖出回购应计利息  
> 明细全价合计 = 估值表卖出回购金融资产款  
> 回购标的金额合计 = 筛选后正回购“结算金额（元）”合计

逆回购：

> 明细净价合计 = 估值表买入返售本金部分  
> 明细应计利息合计 = 估值表买入返售应计利息  
> 明细全价合计 = 估值表买入返售金融资产  
> 回购标的金额合计 = 筛选后逆回购“结算金额（元）”合计

差额超过配置容忍度时停止。禁止把差额塞入任意一笔。

另做交叉核对：

> 正回购结算金额与融入资金逐笔比较  
> 逆回购结算金额与融出资金逐笔比较

两者不一致时，报告中列出交易标识、源行、结算金额、融入/融出资金和差异。AJ 仍填写结算金额，不得为消除差异而改写结算金额。若差异导致无法唯一匹配或无法解释，则停止该笔填报。

## 时间隔离测试

核验模式必须：

1. 在读取已填报表前保存源数据重放结果；
2. 修改报告日后的交易金额、费用、状态和对手方，重新计算，结果必须不变；
3. 修改到期日不晚于报告日的本金和利息，重新计算，结果必须不变；
4. 最后读取已填报表逐字段比较。

任何扰动导致结果变化都属于失败。

## 格式与模板

- 模板版本与配置一致；
- 工作表名称和顺序未改变；
- 填写说明、版本信息和预留区域未删除；
- 单元格数据验证仍存在；
- 金额保持数值类型；
- 编码保持文本类型；
- 利率底层类型与 rate_storage_mode 一致；
- 日期和币种符合配置；
- 保存后重新打开，关键字段显示正常。

## 必须停止

出现任一情况不得交付为可提交文件：

- 缺少必需源文件；
- 估值日期不一致；
- 产品参数或字典缺失；
- 交易无法唯一匹配；
- 估值表没有对应期末余额；
- 交易查询“结算金额（元）”缺失或为 0；
- 未识别的市场、方向、模板版本或资产类别；
- 分笔合计无法回勾估值表；
- 全价小于净价且没有明确账务依据；
- 同一编码重复；
- 未来数据扰动改变结果；
- 目标模板格式被破坏。

可以输出草稿和问题清单，但标题和结论必须明确写“不可提交”。

## 核验报告

至少包含：

1. 报告日、产品和源文件清单；
2. 候选、保留和排除记录数；
3. 正逆回购笔数；
4. 净价、应计利息、全价和本金汇总；
5. 结算金额与融入资金/融出资金的逐笔差异；
6. 逐字段差异；
7. 未来数据扰动结果；
8. 静态参数及其生效日期；
9. 未验证的方向、市场或模板版本；
10. 最终状态。

## 状态定义

| 状态 | 含义 |
|---|---|
| 通过 | 所有适用检查通过，可按授权提交 |
| 有条件通过 | 数字通过，但存在需要业务确认的非金额格式或代码 |
| 不通过 | 数字、时间隔离、匹配或控制数存在错误 |
| 不可验证 | 缺少源文件、参数、字典或对应业务样本 |

不要把“当前样本复现成功”描述为“所有未来报告都已验证”。样本内回归和新报告日样本外验证必须分开披露。

## 交付文件

填写模式通常输出：

- 新的委外资产明细文件；
- 新的资产要素登记文件；
- Markdown 核验报告。

核验模式输出 Markdown 核验报告。除非用户明确要求修复，不修改已填报表。
